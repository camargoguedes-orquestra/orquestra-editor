Editor avançado de conteúdo

Crie documentos, formate textos e trate imagens com enquadramento visual preciso — tudo em um único ambiente.

● Componentes reutilizáveis · Componentes JS e PHP

Atenção: imagens armazenadas em URLs temporárias não persistem após recarregar a página. Execute a demonstração com PHP para habilitar o endpoint de upload.

02 · Zoom e ajustes

03 · Independente

Utilize o uploader em formulários PHP, cadastros, produtos e perfis sem carregar o editor.

Integração JavaScript

Importe apenas os componentes necessários:

import { OrquestraEditor } from './src/editor.js';
import { OrquestraImageUploader } from './src/image-studio.js';

const editor = new OrquestraEditor('#editor', {
  id: 'documento-123',
  uploadUrl: '/backend/upload.php',
  saveUrl: '/backend/save-document.php',
  autosave: true,
  onChange: html => console.log('Atualizado:', html),
  image: { width: 1200, height: 800, locked: false }
});

const uploader = new OrquestraImageUploader({
  element: '#upload', width: 1200, height: 630,
  locked: true, requireAdjustment: true, allowGIF: false,
  format: 'image/webp', profile: 'banner-site',
  uploadUrl: '/backend/upload.php',
  onUpload: result => console.log(result.url)
});

A demonstração do uploader utiliza dimensões fixas 1200×630. Configure o perfil de validação no PHP para impor essas dimensões no servidor. O retorno de upload é JSON com {"url":"/backend/uploads/arquivo.png"}. Leia o README para regras de autenticação e produção.
